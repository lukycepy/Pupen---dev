K aplikaci celé sady migrací je potřeba:
  1. Mít spojený Supabase projekt (supabase link)
  2. Místo -p parametr používat SUPABASE_DB_PASSWORD env var (kvůli pooleru)
  3. Buď:
     - Supabase CLI: npx supabase db push --linked --include-all --yes
     - Nebo Node.js: MIGRATE_INCLUDE_LEGACY=true npm run db:migrate
  4. Ověřit stav: npx supabase migration list --linked
  5. Pokud schema_migrations chybí záznamy, spustit npm run db:migrate
